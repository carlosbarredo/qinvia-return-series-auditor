# Security policy

## Supported versions

Security fixes are applied to the latest code on the `main` branch. This project does not currently maintain parallel release branches.

## Reporting a vulnerability

Please do not publish vulnerability details that could put users or their data at risk. Use GitHub's **Report a vulnerability** option in the repository Security tab when it is available. Otherwise, open an issue requesting a private contact channel without including sensitive details.

Include the affected version or commit, a minimal reproduction, the potential impact, and any known mitigation. You should receive an acknowledgement within seven days. A fix and disclosure timeline will be coordinated after the report is reproduced and assessed.

Ordinary correctness bugs, questionable statistical thresholds, and unexpected audit findings can be reported through the public issue tracker.
